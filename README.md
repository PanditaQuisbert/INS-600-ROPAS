# 🔥 HYPE STREET - Tienda de Ropa Urbana

![HYPE STREET](https://images.unsplash.com/photo-1556905055-8f358a7a47b2?w=1200&h=400&fit=crop)

> **La tienda de streetwear más exclusiva. Drops limitados. Estilo sin límites.**

## 🚀 Descripción

**HYPE STREET** es una landing page moderna para una tienda de ropa urbana/streetwear. Diseñada con una estética bold, asimétrica y llena de actitud, inspirada en marcas como Supreme, Off-White y BAPE.

## ✨ Características

- 🎨 **Diseño Streetwear/Urban** con estética bold y asimétrica
- 🌙 **Modo oscuro/claro** con persistencia
- 📱 **100% Responsive** (mobile-first)
- ⚡ **Animaciones modernas** (glitch, marquee, hover effects)
- 🛒 **Carrito funcional** con localStorage
- 🔥 **Countdown** para próximos drops
- 🎯 **Filtros de productos** por categoría
- 💬 **Botón WhatsApp** flotante
- ⚡ **Optimizado para SEO**

## 🛠️ Tecnologías

- **HTML5** semántico
- **Tailwind CSS** (vía CDN)
- **JavaScript** vanilla
- **Font Awesome** para iconos
- **Google Fonts** (Bebas Neue + Inter)
